# مكتبة رفوف

قصص من تأليف الطلاب، تُقرأ وتُقلَّب كالكتاب العربي. الموقع مجاني، بلا إعلانات، وبلا منصّات خارجية.
تصميم وإعداد: أ. عائشة البروانية

## النشر على GitHub Pages
1. أنشئي مستودعًا جديدًا على GitHub (مثلًا: rufuf).
2. ارفعي كل محتويات هذا المجلد كما هي: index.html، وadd-story.html، ومجلد books.
3. من Settings ثم Pages، اختاري Branch: main، ثم احفظي.
4. يصبح الرابط بهذا الشكل: https://اسم-حسابك.github.io/rufuf/

## إضافة قصة جديدة
افتحي صفحة add-story.html في الموقع، واختاري ملف القصة (PDF)، فيُنزَّل لك مجلد الصفحات والسطر الذي تلصقينه في index.html.
